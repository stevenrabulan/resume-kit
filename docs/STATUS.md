# Status

Where the repo stands. Not a decision record — see `docs/adr/` for those.

Last updated 2026-08-18.

## Verified

Checked on macOS at build time:

- `scripts/setup.sh` passes every check
- The example PDF was generated by the real toolchain, and both pages were
  visually reviewed
- `.gitignore` verified file by file, for both what must be ignored and what must
  stay tracked
- `check-clean.sh` detectors tested against a planted leak file; email, phone,
  LinkedIn, and street-address patterns all fired
- Git history scanned end to end for credentials and real contact data. Clean.
  The only personal data in the repo is the copyright holder in `LICENSE`

- The repo is public at `https://github.com/stevenrabulan/resume-kit`, marked as
  a **Template repository**, with a description and topics set
- `.github/workflows/ci.yml` ran on the first push and passed on both
  `ubuntu-latest` and `macos-latest`

## Not verified

- The **Windows browser paths** in `scripts/txt_to_pdf.js` and `scripts/setup.sh`
  were written from knowledge and have never run on Windows
- The **Puppeteer fallback path** has never been exercised. CI finds a system
  browser on both runners, so it does not cover this either
- **Archive-first onboarding is written but never run end to end.** No real
  archive has been through extraction, the Confirmation Pass, or the gap-fill
  interview. The Google Docs export steps were written from knowledge and not
  walked through against the live Drive and Takeout screens. This is new,
  untested, and replaces the interview-first flow that was verified

Linux is now covered: `.github/workflows/ci.yml` runs `scripts/setup.sh` and a PDF render
on `ubuntu-latest` alongside `macos-latest`. If someone reports a PDF failure,
check whether it is Windows, the Puppeteer fallback, or the new onboarding path
before anything else.

## Open

- Usage telemetry and contact follow-up is **tabled, not rejected**. Designed to
  the point of being resumable in `docs/drafts/telemetry-and-consent.md`, which
  also lists the existing commitments it contradicts.
- `LICENSE` names a copyright holder. That name is the only personal data in the
  repo and the only expected hit from `check-clean.sh`.

## Excluded from the public kit

Cut from the private original, for reference:

| Cut | Why |
| --- | --- |
| Google Docs integration (620 lines, OAuth) | Support burden, least-finished piece, and the workflow it belonged to already advised against using Google Docs |
| Four hardcoded `generate_resume*.js` files | Not generators. Resume content was inline as JS constants, so each application spawned a copy |
| Interview-prep cheat sheets | Personal notes, including one for a named assessment vendor |
| Networking transcripts and scheduling QR code | Personal |
| Application history entries | Personal. The directory ships empty and gitignored |
| Archived resumes | 27 real documents |
